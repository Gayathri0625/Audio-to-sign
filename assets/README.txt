SignSpeak Mini Demo — Assets Directory
=======================================

This directory is reserved for sign language assets (images, GIFs, 3D model references)
that would be used in the full SignSpeak research implementation.

In this simplified conference demo, sign mappings are represented using:
- Emoji indicators (🤟 for matched signs, ❓ for fallback)
- Text-based gloss labels (e.g., HOSPITAL, GOING)

The full research architecture uses a 3D sign language avatar
rendered via Unity/Blender to perform actual sign language animations.
